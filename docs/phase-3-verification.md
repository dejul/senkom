### Architecture and contract

Laravel issues an opaque credential encrypted with framework Crypt, separate from the Viewer bearer token. Default lifetime is 60 seconds; validated configuration bounds are 15-300 seconds. Claims bind Viewer token hash, map, camera, static gateway path, read action, protocol, issuer, audience, issue time, and expiry. MediaMTX 1.21.4 external HTTP auth calls Laravel at the playback boundary. Each callback rechecks Viewer token revocation/expiry, map binding, published snapshot checksum/schema/camera eligibility, camera row, and enabled private-source row. Source URI is not read or decrypted for playback and is never sent to MediaMTX. No dynamic source provisioning or SSRF reachability exists in this batch.

API: `POST /api/v1/viewer/maps/{mapId}/cameras/{cameraId}/playback-sessions`, Viewer bearer auth, body `{ "protocol": "hls" | "webrtc" }`. Response contains opaque session ID/token, map/camera/protocol, configured playback endpoint, Basic auth scheme/user, and issue/expiry metadata. Response uses `Cache-Control: no-store, private` and `Pragma: no-cache`. The endpoint rejects unknown fields, unsupported protocols, missing/invalid Viewer token, wrong map, unpublished/disabled camera, missing/disabled source, and untrusted Origin. It accepts no client URL, path, or destination. OpenAPI and generated TypeScript contract are updated.

Origin policy allows only configured exact origins and a narrow POST preflight with Authorization/Content-Type. MediaMTX HLS/WebRTC origins are explicit. Origin is supplementary; the auth callback is the access boundary. Compose binds RTSP/HLS/WebRTC/ICE only to loopback. Gateway control API, metrics, pprof, RTMP, SRT, and MoQ are disabled. Publisher uses a separate synthetic-only credential and static paths `lab`/`lab-b`. Production requires internal callback reachability, TLS, trusted origins, and network/firewall policy; operational sources remain deferred until approved SSRF/egress controls exist.

### Expiry and revocation semantics

The token is replayable for multiple HLS playlist/variant/segment and WebRTC signaling requests until expiry; it is not single-use. Focused browser probing sent real SDP to WHEP: missing authorization and an expired session returned HTTP 401. HLS master, variant and segment after expiry returned HTTP 401. A browser test observed an established WebRTC connection continue rendering after token expiry; the gateway does not terminate an active peer. The parent acceptance requires short-lived authorization but does not require forced teardown of established peers; active-peer revocation remains a documented limit.

| State change                        | New session issuance                                            | Previously issued token on next gateway callback                        | Established WebRTC peer                |
| ----------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------- | -------------------------------------- |
| Viewer token revoked/map grant gone | Denied (401)                                                    | Denied (401); covered by focused API test                               | Not actively terminated                |
| Camera removed/disabled in snapshot | Denied by current published-camera eligibility                  | Denied by eligibility recheck; implementation reviewed                  | Not actively terminated                |
| Private source disabled             | Denied                                                          | Denied; covered by focused API test                                     | Not actively terminated                |
| Private source deleted              | Denied                                                          | Denied; covered by focused API test                                     | Not actively terminated                |
| Enabled source URI replaced         | Allowed while camera/source remain eligible                     | Still accepted until token TTL; covered by focused API test             | Existing gateway peer remains attached |
| Playback token expired              | New token can be issued if Viewer/source/camera remain eligible | HLS and new WHEP signaling denied (401); covered by focused gateway E2E | Continues rendering                    |

The source URI is not part of the playback claim and is not read by gateway authorization. URI replacement therefore does not revoke an issued token; the static lab gateway path remains bound to map/camera/protocol. Map grants are represented by map-bound Viewer tokens; revoking that token denies issuance and later callbacks. Active WebRTC disconnect is not implemented for expiry, revocation, disable, deletion, or map changes; do not describe token TTL as the maximum lifetime of an already-established stream.
